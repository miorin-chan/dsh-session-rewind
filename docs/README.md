## 实现

插件通过 `conversation.input.right` 观察输入框从可编辑进入发送锁定，通过当前客户端的 transcript 回显获得请求 ID。
`conversation.chat.user.before` 把撤销按钮挂载到原生消息操作行，复用原生 Tooltip、复制按钮样式和行内布局。
这一步依赖 0.2.2-rc.5 的公开插槽容器及消息操作行标记。
操作行不可用时，撤销入口留在输入框旁。

宿主还保留对应的 Inbox 条目时，插件按请求 ID 找到精确条目并尝试移除。
插件通过会话的追加草稿接口恢复正文，并在输入框解除发送锁定后读取最新草稿。

## 验证

- `npm test` 构建插件并测试注册清理、回复判定、精确撤回和草稿恢复。
- `npm run check` 另外校验类型、本地构建产物和支持的 DSH 版本。
- DSH 0.2.2-rc.5 的一次性 profile 在 Chrome 中比较浅色与深色下撤销和复制按钮的尺寸、颜色、间距，
  并验证首段助手正文出现时收起撤销入口。
